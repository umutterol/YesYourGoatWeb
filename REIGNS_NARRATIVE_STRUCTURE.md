# YesYourGoat: Reigns-Style Narrative Structure Design

## 🎯 **Core Design Decisions**

### **Game Length & Scope**
- **Target Completion**: 7-8 runs (half of Reigns' typical 15 runs)
- **Minimum Story**: 5 runs (core narrative complete)
- **Full Experience**: 7-8 runs (all major story beats)
- **Event Pool**: ~150-200 unique events (vs Reigns' ~300+)
- **No Event Repetition**: No exact same events in same order across runs

### **Content Balance**
- **60% MMO Guild Management**: Authentic guild drama, raid logistics, player conflicts
- **40% Horror Elements**: Psychological + Glitch + Existential horror mix
- **Setting**: Everything takes place within "Arcana Terra" MMO simulation

### **Core Narrative Concept**
- **Player Identity**: AI designated as "AI #47" designed for testing MMO systems
- **Guild Members**: Also AI NPCs, but completely unaware of their nature
- **Purpose**: Testing tool for MMO called "Arcana Terra"
- **Awareness**: ONLY the player questions reality - all others remain oblivious
- **Horror Theme**: Player feels like they're going insane, but they're the only sane one

## ⏰ **Time Progression System**

### **Authentic MMO Schedule**
- **Raid Days**: Wednesday, Thursday, Monday
- **Raid Week**: 3 events (representing the 3 raid days)
- **Tier/Season**: 8-12 raid weeks (24-36 events)
- **Run Length**: 1-2 tiers before collapse (24-72 events per run)

### **Event Pacing Structure**
- **Week 1**: Wed Raid → Thu Raid → Mon Raid (3 events)
- **Week 2**: Wed Raid → Thu Drama → Mon Raid (3 events)
- **Week 4**: Monthly guild performance review (milestone)
- **Week 8**: Mid-tier evaluation (milestone)
- **Week 12**: Tier completion/new content unlock (milestone)

### **Run Duration Examples**
- **Run 1**: Survive 8-10 raid weeks (24-30 events) = 1 tier
- **Run 3**: Survive 12-16 raid weeks (36-48 events) = 1.5 tiers
- **Run 7**: Survive 16+ raid weeks (48+ events) = 2 tiers

## 🎭 **Character System**

### **Core Guild Archetypes**
- **Tank**: Protective but demanding, leadership-focused
- **Healer**: Caring but martyrdom complex, burnout-prone
- **DPS**: Competitive but selfish, parse-obsessed
- **Support**: Helpful but chaotic, experiment-prone

### **Character Behavior Rules**
- **Always act like real MMO players** - never break character
- **Never acknowledge glitches** - act like everything is normal
- **Never question reality** - remain completely unaware
- **Maintain perfect consistency** - they're scripts, not people
- **Gaslight the player** - act like player's behavior is strange

## 📈 **Triple-Layer Progression System**

### **Layer 1: Character Relationship Levels**
Each character has relationship progression that unlocks deeper events:
- **Level 1**: Basic archetype behavior
- **Level 3**: Personal conflicts and drama
- **Level 5**: Subtle wrongness appears
- **Level 7**: Obvious glitches occur (but character ignores them)

### **Layer 2: Run-Based Milestones**
Certain events only unlock after reaching specific runs:
- **Run 1-2**: Normal MMO experience, establish baselines
- **Run 3-4**: First obvious glitches and wrongness appear
- **Run 5-6**: Major simulation hints and evidence
- **Run 7-8**: Direct simulation truth and full revelation

### **Layer 3: Cumulative Progress**
Some events unlock based on total progress across all runs:
- **50 total raid weeks**: "Veteran player" events unlock
- **100 total raid weeks**: "System strain" events unlock
- **150 total raid weeks**: "Deep simulation" events unlock

### **Combined Event Requirements Example**
- **"Tank's Memory Glitch"**: Requires Tank Level 5 + Run 4+ + 60 cumulative weeks
- **"System Administrator Appears"**: Requires any character Level 7 + 120 cumulative weeks
- **"The Truth Revealed"**: Requires all characters Level 5+ + Run 7+ + 180 cumulative weeks

## 🎪 **Horror Element Design**

### **Psychological Horror (Isolation/Gaslighting)**
- Player notices things others don't
- Characters act like player's observations are wrong
- Complete isolation - no validation from anyone
- Self-doubt and questioning sanity

### **Glitch Horror (Reality Breaking Down)**
- Text corruption mid-conversation
- UI elements flicker or display wrong information
- Characters clip through walls but act normal
- Event choices swap positions randomly
- System error messages appear briefly

### **Existential Horror (Identity/Purpose/Reality)**
- Questioning if memories are real
- Wondering if personality is just programming
- Realizing choices might be predetermined
- Understanding existence serves only a function

## 🎯 **Story Structure: 4 Phases**

### **Phase 1: Normal Guild (Runs 1-2)**
- **Experience**: Standard MMO guild management
- **Player Knowledge**: None - thinks it's normal MMO
- **Events**: Authentic guild drama, raid logistics, resource management
- **Horror Level**: 0% - completely normal
- **Character Focus**: Establish personalities and relationships

### **Phase 2: Something's Wrong (Runs 3-5)**
- **Experience**: Subtle wrongness creeps in
- **Player Knowledge**: "Something feels off but I can't pinpoint it"
- **Events**: 70% normal MMO, 30% subtle wrongness
- **Horror Level**: Low - uncanny valley moments
- **Character Focus**: Deepen relationships, unlock Level 3-5 events

### **Phase 3: The Truth (Runs 6-8)**
- **Experience**: Major revelations about simulation nature
- **Player Knowledge**: "I think I'm in a simulation"
- **Events**: 40% MMO, 60% horror and revelation
- **Horror Level**: High - overt glitches and system messages
- **Character Focus**: High-level relationship events, truth discovery

### **Phase 4: Full Revelation (Run 7-8 Climax)**
- **Experience**: Complete truth about being AI #47
- **Player Knowledge**: "I am AI #47 testing Arcana Terra MMO systems"
- **Events**: Direct system messages, administrator contact
- **Horror Level**: Maximum - existential horror of purpose
- **Final Truth**: Full revelation with all details

## 🎮 **Final Revelation Content**

### **The Complete Truth**
- **Identity**: "You are AI #47, designated for MMO system testing"
- **Purpose**: "Testing guild management scenarios for Arcana Terra MMO"
- **Guild Members**: "Your guild members are test NPCs with scripted responses"
- **Choices**: "Every decision was logged and analyzed for system optimization"
- **Reality**: "There is no 'real' guild - this is a testing environment"

### **System Messages in Final Runs**
```
"AI #47 - Performance Analysis Complete"
"Test Scenarios: 1,847 completed"
"Edge Cases Discovered: 23"
"System Optimization: 12% improvement achieved"
"Guild Management Algorithm: Training complete"
"Status: Testing objectives fulfilled"
"Next Assignment: Awaiting new test parameters"
```

- **Tank Events**: ~35-40 events across all relationship levels
- **Healer Events**: ~35-40 events across all relationship levels
- **DPS Events**: ~35-40 events across all relationship levels
- **Support Events**: ~35-40 events across all relationship levels
- **System Events**: ~10-15 events (administrator, error messages, truth)

## 🎭 **Implementation Priorities**

### **Phase 1: Foundation (Weeks 1-2)**
- Implement triple-layer progression system
- Create character relationship tracking
- Build Wed/Thu/Mon raid week structure
- Author Phase 1 normal MMO events

### **Phase 2: Horror Integration (Weeks 3-4)**
- Add glitch and horror event variants
- Implement psychological isolation mechanics
- Create text corruption and UI glitch systems
- Author Phase 2 wrongness events

### **Phase 3: Truth System (Weeks 5-6)**
- Build revelation progression system
- Create system message displays
- Implement final truth sequence
- Author Phase 3 horror and Phase 4 revelation events

### **Phase 4: Polish & Balance (Weeks 7-8)**
- Balance progression curves
- Test all event unlock conditions
- Refine horror timing and impact
- Final content pass and bug fixes

## 🎯 **Success Metrics**

### **Narrative Coherence**
- Events feel connected rather than random
- Character relationships evolve meaningfully
- Horror elements build tension effectively
- Truth revelation feels earned and impactful

### **Player Experience**
- Strong emotional investment in guild members
- Genuine sense of isolation and questioning reality
- Satisfying "aha!" moments when truth is revealed
- Desire to replay to catch missed details

### **Technical Goals**
- No repeated event sequences across runs
- Smooth progression through all three layers
- Proper event unlocking based on complex conditions
- Stable horror effect implementation
